# Nox Board Keyboard 🇲🇲
A 100% offline, privacy-first Myanmar and English keyboard for Android.

## Features
- 🛡 **Absolute Privacy:** Zero data collection, no internet permission required.
- 🎨 **Customization:** Fully customizable themes, key sizes, and colors.
- ⚡ **Productivity:** Double-tap shortcuts, spacebar cursor control, and more.
